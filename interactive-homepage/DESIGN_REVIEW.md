# Interactive Homepage Design Review

This prototype is intentionally separate from the stable homepage at `../index.html`.

## Sources Reviewed

- Toss official homepage: https://toss.im/
- Apple Korea official homepage: https://www.apple.com/kr/

## Applied Principles

- Toss: one clear promise per section, plain Korean copy, modular service blocks, repeated interaction patterns.
- Apple: strong first-viewport identity, restrained navigation, high visual focus, product-like section hierarchy.
- Choi Youngryul content: reorganized around `발견, 정의, 해결, 발전`, then connected to `VECTOR Architecture`, `4M Motion`, trajectory, and contact.

## Stability Boundary

The current production homepage files remain untouched by this prototype route. This experiment lives under `/interactive-homepage/` so it can be reviewed without changing the final public root page.
